# Cross-view_V2I

This repository is about our work on cross-view vision-aided Proactive BS selection and Beam Prediction for mmWave V2I communications.

Dataset

The dataset is publicly available on Hugging Face:

[https://huggingface.co/datasets/huzijiao/Cross-view_Wireles_MIMO_Dataset/tree/main](https://huggingface.co/datasets/huzijiao/Cross-view_Wireless_MIMO_Dataset)

A detailed description of the dataset generation pipeline can be found in:

docs/Cross_view_V2I_MIMO_Wireless_Dataset_Generation.pdf
